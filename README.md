# G-11 Courtyard progress site

Live page: https://mabubakar18.github.io/G-11-Courtyard-Site-Progress/

## Files
- index.html: the whole site. Progress data is embedded in it.
- manifest.json, icon-192.png, icon-512.png, apple-touch-icon.png, sw.js: home-screen install and offline copy.
- hero.jpg, imarat-logo.png, renders/: images used on the site.

## Updating
1. Replace index.html with the new version (Add file > Upload files, same name).
2. Commit. GitHub Pages republishes in one to two minutes.
3. Phones pick up the new version the next time the site is opened with internet.
